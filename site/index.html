Do zero à primeira consulta

Três passos. Um único executável.

O painel local cuida da configuração. Depois, seu cliente de IA inicia o MCP quando precisar.

  1. 01
    $ go build

    Compile o projeto

    Baixe o código aberto e gere um executável para macOS, Windows ou Linux.

  2. 02
    Conectado

    Conecte seu Chatwoot

    Informe URL, conta e token no painel. A conexão é testada antes de salvar.

  3. 03
    IA↔CW

    Adicione ao cliente MCP

    Copie a configuração pronta, reinicie o cliente e converse com seus atendimentos.

Segurança por desenho

Seu token não precisa entrar na conversa.

A credencial é configurada no painel local e armazenada em um arquivo restrito do usuário. Os blocos de configuração dos clientes MCP apontam apenas para o executável.

  • 01
    Painel em loopback

    A interface escuta somente no seu computador.

  • 02
    Permissões do Chatwoot

    O MCP só acessa o que o token do usuário já permite.

  • 03
    Envio sem repetição automática

    Falhas ambíguas não geram uma segunda mensagem por conta própria.

Perguntas frequentes

Antes de conectar.

Preciso deixar o painel aberto?

Não. O painel configura e testa a conexão. Depois de salvo, o cliente de IA inicia o comando MCP diretamente.

Funciona com qualquer Chatwoot?

O projeto usa a Application API do Chatwoot. Você precisa da URL da instalação, do ID da conta e de um token pessoal com as permissões necessárias.

As mensagens são copiadas para outro banco?

Não na versão atual. O MCP consulta a API do Chatwoot quando uma ferramenta é chamada e não mantém um índice próprio das conversas.

A IA pode enviar mensagem sem eu pedir?

Leituras e envios são ferramentas separadas. Uma resposta exige uma chamada explícita com o ID da conversa e o texto; seu cliente de IA ainda pode aplicar suas próprias regras de confirmação.

Posso usar pelo celular ou pela web?

A versão atual usa MCP local por stdio, então o cliente precisa rodar no mesmo computador. Um transporte remoto seguro está no roadmap.

É gratuito?

O Chatwoot MCP é um projeto aberto sob licença MIT. Sua instalação Chatwoot e o cliente de IA podem ter custos próprios.
